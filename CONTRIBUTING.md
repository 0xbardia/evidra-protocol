# Contributing

Open an issue or pull request with a focused description of the problem and its verification. Keep changes small, add a regression test for behavior fixes, and run the relevant workspace checks (`pnpm typecheck`, `pnpm lint`, and `pnpm test`).

Do not modify `contracts/`, add credentials or wallet data, or claim a production wallet test that was not performed. Database migrations must be backward-compatible and documented. See [`SECURITY.md`](SECURITY.md) for vulnerability reports.
