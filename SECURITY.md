# Security policy

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** action on this repository when it is available. If private reporting is not enabled, contact the repository owner through GitHub before publishing technical details. Please do not include wallet secrets, personal information, or working exploit payloads in a public issue.

There is no published bug bounty program. Reports should include the affected version or commit, impact, and the minimum steps needed to reproduce the issue. The project will acknowledge reports and coordinate disclosure when practical.

Do not test against production wallets or submit state-changing transactions without explicit authorization. Contract source and deployed V1 addresses are frozen; application changes do not authorize contract modifications or redeployment.
