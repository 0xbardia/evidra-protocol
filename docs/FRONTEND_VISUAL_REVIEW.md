# Evidra Frontend — Visual Review

Date: 2026-09-22

## Overall read

The interface now reads as a protocol workspace rather than a generic Web3
dashboard. Warm paper surfaces and graphite type provide the base; vermilion
marks protocol activity, moss/acid marks positive state, and amber is reserved
for attention. The visual language stays flat and editorial instead of
building every element out of shadows, gradients, and rounded cards.

## Landing

The hero has one clear sentence, three useful exits, and a compact Studio Dev
context line. The custom diagram advances through specification, evidence,
policy, consensus, and verdict stages. Pointer hover and the timed stage
change explain the mechanism; they are disabled or simplified under reduced
motion. The proof strip below the hero reinforces three product truths without
adding another marketing block.

The page narrative is ordered as problem, mechanism, provenance, registry,
use cases, developer integration, transparency, and documentation. It avoids
fake customers, usage numbers, partnerships, or inflated protocol claims.

## Application

- Overview leads with protocol status and useful recent activity. During RPC
  degradation it labels the projection as cached and finalized reads as
  delayed.
- Fact Registry is a compact searchable list with outcome, freshness, policy,
  template, and mutability filters.
- Fact detail leads with the proposition and outcome, then separates canonical
  resolution from latest attempt before showing validity, evidence, history,
  and technical identifiers.
- Create Fact is a deliberate eight-step flow. The mobile step grid keeps all
  steps reachable instead of hiding them behind a clipped horizontal strip.
- Docs uses a quiet reading layout with a desktop rail and a mobile select,
  leaving the content as the visual focus.

## Responsive review

The public route sweep covered eight desktop, tablet, and phone sizes. No
horizontal overflow or clipped primary control was observed. The mobile
Create Fact wizard, docs selector, navigation drawer, evidence metadata, and
Fact identifiers were specifically inspected.

## Motion review

Motion is limited to protocol explanation and state feedback: hero sequence,
diagram stage, section reveal, control feedback, and transaction progress.
The global reduced-motion rule removes transitions that do not aid
understanding, while the content and controls remain available.
