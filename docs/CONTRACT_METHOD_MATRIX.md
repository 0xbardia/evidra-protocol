## Cross-cutting rules

1. Transaction submission is not finalized protocol state; reconcile with latest-final reads.
2. The backend never signs as a user or impersonates a callback target. Resolver and callback writes are contract-to-contract paths.
3. Cache exact versioned records and invalidate from finalized events; never derive canonical outcome from latest resolution alone.
4. `quote_resolution_fee` covers configured protocol fees only; GenLayer execution/network cost is separate.
5. The post-SSRF V1 Registry validator is a strict HTTPS/domain-only allow model: all direct IP literals, localhost aliases, userinfo, fragments, malformed authority, and explicit ports other than 443 are rejected. The Resolver revalidates every collected URL before any Web Module call. DNS resolution and redirect destination filtering remain GenVM Web responsibilities.
6. `mark_callback_result` is caller-authenticated but not state-transition guarded (LOW-002); `EvidraResolver` drops URL query/port components while deduplicating (LOW-003).
